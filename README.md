# Neon Prompter (Android)

Standalone Android version of the Neon News prompter. Voice-follow runs on an
offline speech recognizer inside the app, one continuous session, no Chrome,
no "using your microphone" notifications, no internet needed for listening.

The web prompter at https://neonnews-cloud.github.io/neon-prompter/ is a
separate repo and is not touched by this one.

Every push to main builds a new APK. Get it from Releases → latest → NeonPrompter.apk.

Getting a script in:
- paste it in the app, or
- share text to "Neon Prompter" from any app, or
- open a desk "Prompter app" link and pick Neon Prompter (needs the link
  enabled once: Android Settings → Apps → Neon Prompter → Open by default →
  Add link).
